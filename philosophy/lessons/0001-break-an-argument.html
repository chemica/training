Lesson 1 · Argument analysis · 10–15 minutes

Break an argument without breaking the conversation

Learn to turn ordinary speech into a clear map of reasons. It is the first move in honest disagreement—and a practical defence against believing whatever feels good.

Your win for today

By the end, you will be able to identify a conclusion, extract its premises, and supply a hidden premise without putting words into someone’s mouth.

1. Find the job each claim is doing

In philosophy, an argument is not a quarrel. It is a set of claims in which some—the premises—are offered as reasons for another—the conclusion. A passage can contain disagreement, explanation, rhetoric, or description without containing an argument at all. What makes it an argument is this support relationship. This functional account follows the Internet Encyclopedia of Philosophy’s overview of arguments.

We should delay the release. The authentication tests are still failing.

The order can mislead you. The conclusion appears first, and the reason follows:

P1The authentication tests are still failing.CWe should delay the release.

Words such as because, since, and given that often introduce premises. Words such as therefore, so, and thus often introduce conclusions. Treat these as clues, not syntax rules. Ask the deeper question. What is the speaker trying to get me to accept, and what reasons are offered for it?

A premise and a conclusion are roles, not kinds of sentence. The same claim can be a conclusion in one argument and a premise in another.

Retrieval check 1

Do not look back. Which question best locates the conclusion?

2. Convert prose into a map

Reconstruction strips away verbal noise while preserving the reasoning. Put each distinct claim on its own numbered line. Remove repetition and scene-setting. Replace pronouns only when necessary. End with one principal conclusion.

Surely we should not believe a claim just because it comforts us. Comfort is no guide here. After all, false beliefs can be comforting too.

A first pass gives us:

P1False beliefs can be comforting.CWe should not believe a claim merely because it comforts us.

This is already useful. The repeated phrase “comfort is no guide” adds emphasis but no separate reason. “Surely” signals confidence, not evidence. Reconstruction lets us see the inferential skeleton without confusing volume for support.

3. Expose the hidden bridge

Ordinary arguments are often enthymemes. One or more claims are left unstated because the speaker assumes the audience can supply them. Here, the stated premise does not yet connect explicitly to the practical conclusion. We need a bridge:

P1False beliefs can be comforting.HPIf a feature is shared by false and true beliefs, that feature alone is not a reliable basis for belief.CWe should not believe a claim merely because it comforts us.

The hidden premise makes the intended route visible. It is not automatically true just because the argument needs it. Indeed, exposing it tells us exactly where productive disagreement may lie.

A good reconstruction balances two duties:

  1. Fidelity. It must remain recognisably the speaker’s argument, supported by the words and context.
  2. Charity. Where more than one reading fits, prefer a coherent, plausible version over an obviously foolish one.

Charity is not repair without permission. If your hidden premise introduces a new doctrine the speaker might reject, mark it as a question: “Does your reasoning assume that…?” The IEP discussion of argument reconstruction stresses that missing material must be supplied carefully and in context.

Retrieval check 2

Someone says, “Mira promised to help, so she ought to help.” Which hidden premise is most charitable?

4. Only then begin evaluation

Once the map is explicit, inspect two different things. First, the connection. Do the premises genuinely support the conclusion? Second, the inputs. Are the premises true or well justified?

For a deductive argument, the connection is valid when there is no possible case in which all the premises are true and the conclusion false. A valid argument with true premises is sound. These definitions are developed formally in Richard Zach and Aaron Thomas-Bolduc’s forall x: Calgary.

P1If the server is unreachable, the health check fails.P2The health check fails.CThe server is unreachable.

The conclusion might be true, but the reasoning does not guarantee it. The server could be reachable while the health-check code itself is broken. That possible case is a counterexample to validity. The bug becomes obvious once the argument is mapped. In later lessons we will distinguish deductive guarantee from probabilistic support and formalise patterns like this one.

Do not ask “Do I agree?” first. Ask “What is the argument?” Then test its connection and its premises separately.

5. The four-pass reconstruction loop

  1. Locate. What claim is the speaker trying to establish?
  2. List. What distinct reasons are actually stated?
  3. Link. What hidden premise would connect those reasons to that conclusion?
  4. Check. Is your version both faithful and charitable?

Use this loop in moral disputes, political claims, code reviews, and arguments about God. It slows the reflex to attack. Often you will discover that two people accept the same evidence but rely on different hidden bridges—or use the same words for different conclusions.

Final dialogue exercise

Reconstruct this without searching:

A loving God would not remain hidden from sincere seekers. Yet some sincere seekers fail to believe that God exists. That is a serious reason to doubt that a loving God exists.
  1. Write the main conclusion as C.
  2. Write each stated premise as P1, P2, and so on.
  3. Add one plausible hidden premise as HP.
  4. Name one phrase whose meaning needs clarification.
  5. Give the strongest objection to a premise or to the connection.

Then send me your reconstruction. I’ll first assess its fidelity and structure. After that, I’ll take the strongest opposing side and run a short mock debate with you. Ask me any follow-up question if a distinction remains unclear.
