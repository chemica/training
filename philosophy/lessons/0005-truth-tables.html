Lesson 5 · Truth-functional logic · 10–15 minutes

Make every case show its hand

Truth tables turn a claim about every valuation into a finite inspection. Learn to evaluate connectives, classify formulas, and find the one row that breaks an argument.

Lesson 4 introduced propositional symbols, connectives, scope, and necessary and sufficient conditions. Now those symbols acquire a precise semantics. A truth table assigns truth values to atomic sentences, then calculates the value of each larger sentence from its parts. With two atomic sentences there are four valuations. With three there are eight. In general, n atoms require 2n rows.

Your win for today

You will be able to use a complete truth table as an exhaustive test for tautology, contradiction, contingency, and deductive validity in classical truth-functional logic.

One valuation is one test case

Let P mean “The policy reduces suffering,” and J mean “The policy is just.” A valuation assigns each atom either true or false. It does not tell us which assignment describes the actual policy. Instead, it asks what follows under each assignment.

PJP ∧ JP → J
TTTT
TFFF
FTFT
FFFT

The table is exhaustive because it includes every combination of truth values for P and J. This resembles exhaustive testing over Boolean inputs, but do not identify propositions with program variables. A valuation is a formal assignment. Whether it describes a metaphysically, physically, or morally possible situation is a further philosophical question.

This is also why a tautology in truth-functional logic is only a formal surrogate for necessary truth. “Either the policy is just or it is not just” has its truth guaranteed by its connective structure. “Two plus two equals four” may be necessary, but its necessity is not exposed by treating the whole sentence as one atom. Chapter 12 of forall x: Calgary makes this limitation explicit.

The five connective rules

Negation. ¬P reverses P.

Conjunction. P ∧ J is true only when both are true.

Inclusive disjunction. P ∨ J is true when at least one is true, including when both are true.

Conditional. P → J is false only when P is true and J is false.

Biconditional. P ↔ J is true when P and J have the same truth value.

The conditional deserves special care. “If P, then J” rules out the case where P obtains without J. It makes P sufficient for J and J necessary for P. When P is false, the material conditional is true regardless of J. This rule captures an important logical pattern, but it does not by itself capture relevance, causation, explanation, or ordinary conversational suggestion.

Build from the inside out

For a complex formula, create columns for its atoms and then for the smallest subformulas. Work outward until you reach the main connective. Consider ¬P ∨ J.

The final column matches P → J exactly. So the two formulas are logically equivalent. They share a truth value on every valuation. Notice the method. We did not test a few vivid policies and generalise. We checked the entire formal state space.

Read the final column

A complete truth table classifies a formula by the pattern beneath its main connective.

ALL TTautology. True on every valuation. Example. P ∨ ¬P. ALL FContradiction. False on every valuation. Example. P ∧ ¬P. MIXEDContingency. True on some valuations and false on others. Example. P ∧ J.

These labels describe formulas relative to this semantics. “Contradiction” here does not mean an implausible opinion or a heated disagreement. It means false on every truth-functional valuation.

Retrieval check two

What is the classification of (P ∧ J) → P?

Validity is the absence of one forbidden row

Lesson 2 defined a valid deductive argument as one with no case in which all premises are true and the conclusion false. A truth table makes that definition mechanical. Build the columns, then scan only for the forbidden pattern.

P1P → J P2J CP
PJP → JJP
TTTTT
TFFFT
FTTTF
FFTFF

The third row is a countermodel. Both premises are true and the conclusion is false. The argument affirms the consequent and is invalid. One forbidden row defeats validity. If an exhaustive table contains no forbidden row, the argument is valid.

For a formula, inspect the whole final column. For an argument, hunt for a row with every premise true and the conclusion false.

Interleaved check

A table for premises A ∨ B and ¬A, with conclusion B, has no row where both premises are true and the conclusion false. What follows?

A disciplined workflow

  1. Symbolise carefully. A flawless table cannot rescue a mistranslation.
  2. List the atoms. Make 2n rows in a systematic T and F pattern.
  3. Calculate inward to outward. Give each useful subformula a column.
  4. Read for the task. Classify the final column, compare columns for equivalence, or hunt the forbidden validity row.
  5. Translate the result back. Explain what the decisive row means in the original subject matter.

The final step matters in debate. “Row three is T, T, F” is a formal diagnosis. “A text might contain no contradictions yet still be fallible” exposes the live philosophical possibility.

Final exercise. Test a worldview argument

If a revelation is infallible, it contains no contradictions. This revelation contains no contradictions. Therefore, this revelation is infallible.

Let R mean “This revelation is infallible” and N mean “This revelation contains no contradictions.” Without looking back, do five things.

  1. Symbolise the two premises and conclusion.
  2. Build all four rows for R and N.
  3. Mark any row where all premises are true and the conclusion false.
  4. State whether the argument is valid.
  5. Translate the decisive row into an intelligible scenario rather than merely reporting letters.
