Lesson 2 · Deductive logic · 10–15 minutes

Truth here. Truth everywhere.

A true conclusion can be reached badly. A valid argument can begin falsely. Today you will learn to keep those judgments separate—and break bad inferences with one decisive countermodel.

Lesson 1 gave you a two-pass debugger. First test the inference; then test the premises. Now we will make that first pass precise.

Three questions, not one

Suppose somebody argues that Ada is in London because she is in England. You could ask three different questions.

TRUTHAre the individual claims true in the actual world? VALIDITYCould the premises all be true while the conclusion is false? SOUNDNESSIs the inference valid and is every premise actually true?

A deductive argument is valid when there is no possible case in which all its premises are true and its conclusion is false. Validity therefore concerns a relationship, not the actual truth of any one sentence. A valid argument is sound when its premises are also actually true. These are the standard semantic definitions used in introductory formal logic. See forall x: Calgary, Part I.

Actual truth belongs to claims. Validity belongs to inferences. Soundness combines them.

The four useful combinations

Valid, true premises. The conclusion must be true. The argument is sound.

Valid, at least one false premise. The conclusion may be true or false. The argument is unsound.

Invalid, true premises. The conclusion may happen to be true, but the premises do not guarantee it.

Invalid, at least one false premise. Again, the conclusion may be either true or false.

Only one combination is impossible. A valid argument cannot have all true premises and a false conclusion. That impossible row is the whole definition of validity.

Retrieval check 1

All mammals are warm-blooded. Whales are mammals. Therefore, whales are warm-blooded. What is established if both premises are actually true?

Actual does not mean necessary

“London is the capital of the United Kingdom” is actually true. But logic does not make it true in every possible situation. Political history could have unfolded differently. By contrast, “Either London is the capital or London is not the capital” is true under every classical valuation of its component claim. It is a logical truth.

This distinction prevents a common confusion. A valid argument need not contain a conclusion that is true in every possible world. What must hold in every relevant case is the conditional guarantee. Whenever the premises are all true, the conclusion is true too.

P1If the server is offline, the health check fails. P2The server is offline. CTherefore, the health check fails.

The conclusion is contingent. The health check need not fail in every possible situation. Yet the inference is valid because there is no case satisfying both premises while falsifying the conclusion.

Countermodels are failing test cases

A countermodel is one possible interpretation under which every premise is true and the conclusion is false. Think of it as the smallest failing test for a claimed guarantee. One countermodel proves invalidity. A hundred cases in which premises and conclusion are all true do not prove validity, because the forbidden case may still be hiding.

P1If the database is down, login fails. P2Login fails. CTherefore, the database is down.

Construct the countermodel. The database is running, but the identity provider is down. Then P1 is true, because it correctly says what would happen if the database were down. P2 is true, because login does fail. The conclusion is false, because the database is not down. The argument is invalid. Its form is the familiar error of affirming the consequent.

Retrieval check 2

If moral facts exist, some moral judgments are correct. Some moral judgments are correct. Therefore, moral facts exist. Which response directly tests validity?

A mechanical test

  1. Freeze the wording. Identify the premises and conclusion charitably.
  2. Grant every premise. Do not argue with them yet.
  3. Deny the conclusion. Describe a coherent case where it is false.
  4. Check compatibility. Can all those assignments hold together?

If yes, you have a countermodel and the inference is invalid. If no coherent countermodel exists, the argument may be valid—but confidence sometimes requires formalization or proof. Then return to pass two and investigate whether the premises are actually true.

Your turn. A dialogue test

Imagine I say this in a debate.

“If God revealed a moral law, some moral duties would be objectively binding. Some moral duties are objectively binding. So God revealed a moral law.”

Reply to me in four moves.

  1. Name the conclusion and say whether you are testing truth, validity, or soundness.
  2. Grant both premises temporarily.
  3. Offer the most philosophically serious countermodel you can.
  4. Explain why your countermodel attacks the inference without yet proving atheism or disproving objective morality.

Send me your answer. I will first mark the logical structure, then defend the argument as strongly as I can so you can practise the next round. Ask follow-up questions about anything unclear.
