Here is your first tool for thinking clearly: treat an argument like a program you need to debug.

An argument is a set of claims in which premises are offered as reasons for a conclusion. Evaluate it in two passes. First, test the connection: could the premises all be true while the conclusion is false? Second, test the inputs: are the premises actually true and justified?

Validity asks about the connection. Soundness also asks about reality.
