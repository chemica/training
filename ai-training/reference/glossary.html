Living reference · Qualification vocabulary

Use precise words.

This glossary grows before new terminology appears in assessed work.

Application request path

AWS service
A capability that AWS provides, such as Lambda or S3.
Resource
One configured instance of a service, such as one Lambda function or one S3 bucket.
Client
Software that sends a request to a service. A browser, mobile application, or another server can be a client.
Request
A message that asks a component to do something.
Response
The result that a component returns for a request.
Synchronous
The caller waits for the work to finish and receive a response.
Asynchronous
The caller submits work and does not wait for all processing to finish.

Identity and access

Principal
An identity that can make a request to AWS. It can represent a person, application, or AWS service.
Authentication
The process that verifies which principal made the request.
Authorization
The decision about whether an authenticated principal can perform a specific action on a specific resource.
IAM role
An AWS identity with permissions that an approved principal can assume. A role supplies temporary credentials.
IAM policy
A JSON document that defines allowed or denied actions, resources, and optional conditions.
Least privilege
The practice of granting only the permissions required for the task.
Temporary credentials
Short-lived access values issued for a session. They reduce the exposure caused by long-lived keys.

Failure and evidence

Failure mode
One specific way in which a component or interaction can fail.
Timeout
A failure that occurs when work does not complete inside an allowed time.
Throttle
A temporary rejection because requests exceed an allowed rate or capacity.
Log
A timestamped record of an event with diagnostic details.
Metric
A numeric measurement recorded over time, such as error count or latency.
Trace
A connected record that follows one request through multiple components.
CloudTrail event
An audit record of an AWS API action. It helps answer who did what, when, and against which resource.
Request ID
An identifier for one request. It helps correlate evidence from different components.
Observability
The ability to understand system state and behavior from evidence such as logs, metrics, and traces.

Cloud infrastructure

Region
A separate geographic area in which AWS operates infrastructure.
Availability Zone
Independent infrastructure locations inside a Region.
Edge location
A site used by edge services to place content or processing near users.
Elasticity
Dynamic adjustment of capacity as demand changes.
High availability
A design goal that keeps a system usable despite component failure.
Shared responsibility
The division between AWS security of the cloud and customer security in the cloud.

Account and cost controls

Root user
The full-access identity created with an AWS account email address.
Federation
Using an external identity system to obtain AWS role access.
Explicit deny
A policy decision that overrides an applicable allow.
AWS Budget
A cost or usage threshold with notifications and optional actions.
Tag
A key-value label attached to an AWS resource.

AI and generative AI

Supervised learning
Learning from examples that include known target labels.
Unsupervised learning
Learning patterns without target labels for the pattern sought.
Classification
Predicting a category.
Regression
Predicting a numeric value.
Clustering
Grouping examples by similarity without supplied target groups.
Token
A unit of content processed by a model.
Context window
The token capacity available for model input and output.
Embedding
A numeric vector representing semantic properties of data.
RAG
Retrieval-augmented generation: retrieving external information and supplying it as model context.
Fine-tuning
Additional training that adjusts model behavior using task-specific examples.
Few-shot prompt
A prompt containing a small set of task examples.
Guardrail
A configured safety or policy control applied to model input or output.
Evaluation dataset
A fixed set of representative inputs used to compare behavior.

Responsible AI

Governance
The decisions, ownership, policies, controls, and evidence used to direct and oversee AI.
Preventive control
A control intended to stop an unwanted event.
Detective control
A control intended to identify an event or condition.
Corrective control
A control intended to restore an acceptable state.
Human oversight
Meaningful human ability to review, intervene, or override.

Development and delivery

AWS SDK
A language library for constructing and sending AWS API requests.
Lambda handler
The configured entry point for a Lambda function.
Lambda context
Runtime information for one Lambda invocation.
Visibility timeout
The period when an SQS message is hidden after a consumer receives it.
Idempotent operation
An operation whose repeated execution does not create additional unintended effects.
Dead-letter queue
A queue that isolates messages after repeated processing failures.
Infrastructure as code
Version-controlled definitions of infrastructure resources.
Stack
A set of related resources managed as one CloudFormation unit.
Artifact
A versioned output supplied to deployment.
Lambda version
An immutable published snapshot of a Lambda function.
Lambda alias
A named pointer to a Lambda version.
Runbook
Concrete operator instructions for diagnosis, mitigation, verification, and escalation.
