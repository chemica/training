Quick reference · Course roadmap

Learn. Build. Prove. Operate.

The qualification path is a spine. Observable capability is the course.

0 · Safe starting point

Learn: terminal, Git, programming baseline, AWS account safety.
Prove: authenticate safely, run code, inspect HTTP, explain budgets.

1 · AI foundation

Learn: cloud, IAM, cost, AI/ML/GenAI, model choice, responsible AI.
Build: evaluated Bedrock classifier or summarizer.
Qualify: AIF-C01. CLF-C02 remains optional.

2 · AWS application developer

Learn: APIs, Lambda, DynamoDB, queues, events, IaC, tests, CI/CD, observability.
Build: authenticated serverless API with Bedrock inference.
Qualify: DVA-C02.

3 · Production-shaped GenAI

Learn: evaluation, RAG, agents, guardrails, authorization, resilience, cost.
Build: governed RAG assistant and bounded agentic workflow.
Prove: another builder can deploy, evaluate, and operate both.

4 · Professional endpoint

Learn: from real users, incidents, reviews, and measured outcomes.
Operate: a controlled business pilot and improve it from evidence.
Qualify: AIP-C01 after the experience gate.

Always running: retrieve from memory, test behavior, minimize permissions, measure quality and cost, document limitations, and clean up resources.
