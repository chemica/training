Lesson 0005 · AIF-C01 domain 1

Name the learning problem.

Separate AI, machine learning, training, inference, supervised learning, unsupervised learning, and reinforcement learning.

35–45 minutes · AWS Certified AI Practitioner

1 · Orient

Prerequisite: general software development concepts. No mathematics is assessed here.

Outcome: Given a business problem and available data, you can identify the broad learning approach and explain what the model does during training and inference.

Theme · Why the problem comes before the model

Developers usually turn requirements into explicit rules. Machine learning becomes useful when a relationship is better learned from examples than fully expressed as code. That does not mean every uncertain business problem needs ML. We must first identify the decision, available data, desired output, and cost of a wrong answer.

If historical support tickets have correct priority labels, a model can learn to predict those categories. If the business wants to discover unknown groups of similar tickets, there are no target labels to imitate. These are different learning problems and require different evaluation.

AI names the broad capability, while machine learning describes systems that learn patterns from data. Training creates or adapts a model; inference uses that model in an application.

2 · Learn the hierarchy

Artificial intelligence (AI) is the broad field of systems that perform tasks associated with human intelligence. Machine learning (ML) is one approach within AI: algorithms learn patterns from data instead of receiving every decision rule explicitly.

A model is the learned representation used to produce predictions or outputs. Training is the process that adjusts the model from examples or feedback. Inference uses a trained model to produce an output for new input.

3 · Learn the main approaches

Supervised learning

Training examples include inputs and known target outputs called labels. Common tasks are classification and regression.

Unsupervised learning

Training data has no target label for the pattern being sought. Common tasks include clustering and dimensionality reduction.

Reinforcement learning

An agent learns a policy through actions, environmental feedback, and rewards. The objective is cumulative reward, not matching a label for each example.

Feature
An input property used by a model.
Label
The known target value in a supervised training example.
Classification
Predicting a category, such as likely churn or no churn.
Regression
Predicting a numeric value, such as expected demand.
Clustering
Grouping examples by similarity without supplied target groups.

4 · Learn evaluation language

An evaluation metric is a defined measurement of model performance. Accuracy can be misleading when one class is rare. Precision asks how many predicted positives were correct. Recall asks how many actual positives were found. A business cost must determine which errors matter.

Overfitting occurs when a model learns training-specific detail and performs poorly on new data. A held-out test set estimates generalization, provided it represents future use and has not guided repeated tuning.

Worked example

A telecom reseller has historical orders marked “cancelled within 30 days” or “retained.” These labels make churn prediction a supervised classification problem. Customer tenure and support-call count can be features. Training learns from historical labelled examples; inference scores a new order.

If the business wants to discover natural customer segments without target segment labels, that is clustering and therefore unsupervised learning. Neither choice is justified until the intended action and cost of errors are known.
